# Sigil

**探索面向科学文献编号识别的小语言模型领域适配。**

[English](README.md) · **简体中文**

**研究问题：** 领域适配与任务设计如何影响小模型的编号识别和结构化输出？**方法：** 基于 Qwen3.5-0.8B 开展 LoRA、直接 SFT 与 CPT→SFT 对照，并比较完整文档与结构分段输入。**核心发现：** CPT 将语言模型验证损失降低 9.06%，但 19 篇论文的严格 JSON 已知编号恢复为直接 SFT 的 23/210、CPT→SFT 的 18/210；语言建模与抽取表现并不同步。

[训练方法](docs/methods.md) · [实验结果](docs/results.md)

## 1. 从传统实体识别到小语言模型

早期尝试涉及三元组构造、BERT-NER、GLiNER、词频分析和基于掩码语言模型的评分。在实际地质文献中，这些方法容易混入地名、普通实体以及解析产生的异常标点和字符碎片。

地质样品和分析编号缺乏统一命名规则。同一串字符究竟是样品编号、测点编号、地名还是仪器型号，往往需要结合正文语义和表格上下文判断，单纯依赖词形或局部统计特征难以消除这些歧义。

后续因此转向小参数生成式语言模型，尝试利用上下文建模和领域 LoRA 训练完成编号识别。任务要求是原样复制文中实际出现的编号，排除年龄、同位素比值、文献索引等无关数字，不推断未出现的父样品名称，也不自动续号。

早期传统方法的比较来自探索记录，目前归档中可直接复核的训练与定量证据主要集中在后续小模型实验。

## 2. 模型与训练设计

项目以 **Qwen3.5-0.8B** 为底座，在单张 **RTX 3090** 上进行 LoRA 训练，记录中的可训练参数为 **3,194,880 个**。模型加载和参数适配采用 Transformers 与 PEFT，训练代码控制损失范围、输入顺序、优化器及检查点。

训练语料来自真实地质文献，输入同时覆盖正文与表格。DOCX 预处理按文档顺序保留段落、表格行和 Office Math 文本；数学内容以纯文本投影保留，不包含扫描图像 OCR 或公式版式恢复。

模型采用过两类输出形式，以下为格式示意。

**不带类型的编号识别：**

```json
{
  "entity_ids": ["MZ04A", "MZ04A-01", "MZ04A-02"]
}
```

**带类型的编号识别：**

```json
{
  "sample_ids": ["MZ04A"],
  "spot_ids": ["MZ04A-01", "MZ04A-02"]
}
```

两种形式对应不同的任务组织方式。早期路线同时研究识别与类型区分；后续 CPT 对照统一使用 `entity_ids`，重点考察编号识别和输出完整性。

| 主要 CPT／SFT 对照设置 | 实际配置 |
|---|---|
| LoRA | rank 8、alpha 16、dropout 0.05，作用于七类注意力／前馈投影层 |
| 计算与显存 | bf16、batch size 1、梯度检查点、SDPA |
| CPT 目标 | 原始领域文本的自回归语言建模 |
| SFT 目标 | 仅对编号 JSON 答案及 EOS 计算交叉熵 |
| 全文保留 | SFT 不裁切文章，最长实际训练输入为 59,864 token |

## 3. 研究探索

### 3.1 先识别再分类，还是直接分类？

早期设计了两条训练路线：

- **路线 A：** 先学习提取全部编号，再学习带类型抽取。
- **路线 B：** 直接学习从原文识别编号并区分样品与测点类型。

原本的直觉是，先学习编号的共同形态，再学习类型差异，可能降低训练难度。这里的“再分类”仍然是从原文生成带类型列表，并未另建一个接收第一阶段预测结果的分类器。

历史实验呈现出随评测集变化的取舍。例如，在真实全文续训后的开发片段上，直接带类型路线减少了误检，但召回略低；在留出表格上，该路线的精确率和召回率均较高。因此，这些结果更适合用来分析任务组织对行为的影响，尚不足以建立某条路线普遍更优的结论。

部分历史实验继承不同的父适配器，累计更新次数也不同；它们是训练路线比较，与下文同起点的 CPT 对照分别解释。由此形成的研究问题是：**领域适配效果如何受到训练目标和任务顺序影响？**

### 3.2 领域继续预训练是否改善抽取？

另一组实验比较了**直接 SFT**与 **CPT → SFT**。两组使用相同的原始底座和完全相同的新 LoRA 初始化，并对齐 SFT 数据、输入顺序、标签、随机种子和训练设置；进入 SFT 时均重新建立优化器。

CPT 使用 128 篇领域文献、约 286 万目标 token，完成 1,464 次更新。随后两组均使用 64 篇完整真实文章进行 SFT，按相同安排完成 72 次更新。CPT 组在共同的 SFT 阶段之前接受额外训练，因此总计算量并不相等。

固定语言模型验证集包含 8 篇文章、32 个序列和 54,960 个目标 token。CPT 后，验证损失由 **2.1534 降至 1.9583，下降约 9.06%**，但这一改善没有一致转化为编号抽取收益。

| 19 篇完整论文对照 | 直接 SFT | CPT → SFT |
|---|---:|---:|
| 完整 JSON 可用 | 12/19 | 12/19 |
| 仅消费完整 JSON 的已知编号恢复 | 23/210 | 18/210 |
| 包含截断前完整字符串的已知编号恢复 | 52/210 | 28/210 |
| 可恢复口径的文章等权已知召回 | 47.61% | 51.14% |

文章等权召回只对 **11 篇具有已知编号清单的文章**取平均；其余 8 篇空清单属于未知，仍计入输出可用性统计。按编号总量汇总与按文章等权平均的方向不同，不能概括为 CPT 在所有识别指标上均有提升或均无提升。

这一结果提示：**领域语言建模损失的改善，不必然转化为下游抽取能力的稳定提升。** 语言预测、编号识别和结构化输出需要分别衡量。

### 3.3 识别能力与输出交付

生成式编号识别既要找到正确编号，也要正常结束列表。在上述两组实验的 38 次全文生成中，共有 14 次达到输出上限；逐项审查将其分为 **8 次明显重复循环**和 **6 次非原文编号续造**。

部分输出在陷入循环之前已经识别了正确编号。若把所有不完整 JSON 都视为零识别，就会将识别错误与输出交付失败混在一起。

项目因此保留两套口径：严格解析只接受完整的 `entity_ids` JSON；保守前缀恢复则从实际输出的列表开头依次读取完整字符串，在首个截断或格式错误处停止，再按文章去重。它不补齐残缺编号，也不利用标签挑选输出。

两套口径共同区分已识别编号、完整输出可用性和异常生成行为。前缀中存在正确编号，并不代表整个抽取任务已经完成。

### 3.4 完整文档与结构化分段

为考察输入组织的影响，另一组实验固定已训练模型，将同一批 19 篇论文分为 410 个片段，尽量保持表头、样品说明和数据行连续，再汇总各段输出并在篇内去重。

早期切分存在表格边界和标签问题：部分表头与数据分离，13 个加热阶段数值被误列为测点编号。修正版调整了边界，并移除这 13 个已确认的错误标签，得到以下结果：

| 指标 | 整篇输入 | 结构分段 |
|---|---:|---:|
| 已知编号恢复 | 94/210 | 75/210 |
| 文章等权已知召回 | 57.44% | 38.77% |
| 输出编号数，篇内去重后求和 | 481 | 678 |

这里的文章等权召回同样只对 11 篇非空已知清单计算。410 个片段均可解析且无输出截断，**整篇输入条件也没有截断**。分段未改善已知编号召回，且增加了未经逐条核查的额外候选。

结果说明，对当前模型和这组文献而言，**缩短输入并不自动带来更好的识别效果**。上下文组织、任务理解和生成行为都值得进一步研究；本实验不能单独确定其中哪一项是主要原因。

这一组使用另一份固定适配器，与 CPT 对照属于不同实验。410 个输入中，324 个完全相同输入复用历史输出，86 个变化输入在原实验中重新推理；调用次数、总输出预算和重复上下文也与整篇条件不同。

## 4. 当前结论与后续方向

实验逐步将关注点从小模型能否提取编号，扩展到以下问题：

1. 领域知识与上下文如何帮助区分真实编号和文本噪声？
2. 编号识别与类型判断的训练顺序如何影响误检、漏检和类型错误？
3. 为什么领域继续预训练改善了语言预测，却未稳定改善下游抽取？
4. 如何分别衡量实体遗漏、额外生成和输出交付失败？

当前全文评测依赖不完全的已知编号清单，19 篇文章曾在开发过程中反复检查，因此这些结果属于开发／回归对照。额外候选尚未全部人工判定，不能据此计算独立盲测意义上的完整精确率或 F1。

后续计划整理更完整的标准标注，结合年代学数据库和人工校核建立评测，继续比较训练策略、文档组织和输出约束对编号识别及交付完整性的影响。
